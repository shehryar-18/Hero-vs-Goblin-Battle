
C# Console Battle Game ⚔️
Overview
A simple turn based battle simulator built in C#.
Hero vs Goblin, fight continues until one runs out of HP.

Key Concepts
* Object Oriented Programming
* Inheritance
* Method Overriding (Polymorphism)
* Constructors
* Loops and Conditions
* Random critical hit logic 🎯

How It Works
Character is the base class.
Hero inherits from it and adds a critical hit system.
Both characters attack in a loop until one loses all health.
Winner is displayed in the console 🏆
